## Setup tips shown before starting (not checked by the camera)

- Neutral grip, palms facing each other (dp_01).
- Brace core and glutes (dp_03).
- Shoulders down and back, no shrugging (dp_05).
- Elbows track back, don't flare (dp_06).

## Where sources disagree (for the coach to decide)

- **dp_02 top_position:** SL: straight arms; CV: full extension; FB: slightly flexed / not locked
- **dp_06 elbow_path:** FB: close to body (dip); slight flare (chest dip); GF: do not flare; BB: 30-45 deg from torso; CV: track back
- **dp_07 depth:** SL: shoulders below elbows; FB: elbows 90 deg; GF: shoulders level with elbows; CV: upper arms parallel / comfortable; BB: controllable depth only

## Common errors named by the sources

| Error | Do instead | Sources |
|---|---|---|
| Forcing depth before the shoulders can control it | Stop at controllable depth | BB |
| Flaring elbows | Track elbows 30-45 deg behind | GF, BB, CV |
| Inconsistent torso angle through the set | Hold one torso angle | GF |
| Shrugging shoulders | Depress shoulders each rep | GF, CV |
| Using momentum / loose torso | Brace the torso | CV, BB |
| Ring dips before you are ready | Use fixed parallel bars | SL |

## Limitations

- Numbers come from coaching texts, not biomechanics measurements; most limits are [Placeholder] values to be set from labeled reps and a coach (docs/how-scoring-works.md).
- Angles are 2D, from the side nearer the camera; they are only valid when the camera sees the movement from the stated view.
- The pose model has no spine points: rounding or arching of the back can't be measured.
- There is no bar keypoint; the hands stand in for the bar.
