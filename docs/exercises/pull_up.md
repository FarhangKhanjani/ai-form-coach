## Setup tips shown before starting (not checked by the camera)

- Overhand grip, about shoulder-width or slightly wider (pu_01, pu_02).
- Start each rep from a full hang, arms straight (pu_03).
- Pull the shoulder blades down first; don't shrug (pu_04).
- Body straight, no swinging; don't cross the ankles (pu_06).

## Where sources disagree (for the coach to decide)

- **pu_02 grip_width:** NFPT: about shoulder-width; CE: shoulder-width (for beginners); NASM: slightly wider than shoulders; SW: slightly wider than shoulders

## Common errors named by the sources

| Error | Do instead | Sources |
|---|---|---|
| Incomplete range of motion | Full hang to chin over bar | SW, NASM |
| Neck strain / craning to clear the bar | Neutral neck | SW, NFPT |
| Momentum / kipping / swinging | Strict controlled pull | CE, NFPT |
| Shrugging shoulders toward ears | Depress scapulae first | NFPT |
| Crossing ankles | Ankles together or legs straight | NFPT |
| Jerky, uncontrolled descent | Lower with control | NASM |
| Fatigue-driven form break | Stop the set when form degrades | NASM |

## Limitations

- Numbers come from coaching texts, not biomechanics measurements; most limits are [Placeholder] values to be set from labeled reps and a coach (docs/how-scoring-works.md).
- Angles are 2D, from the side nearer the camera; they are only valid when the camera sees the movement from the stated view.

- There is no bar keypoint; the hands stand in for the bar.
